# Development

## Setup

See [Contributing](../CONTRIBUTING.md) for repository setup and required
validation commands. Use the Node version in `.node-version` and install
dependencies with the repository's frozen lockfile.

## Repository commands

The root `package.json` defines the supported development, lint, and
type-check commands. Use those scripts rather than invoking generated output
directly.

## Release and support

Release automation and package metadata are maintained in the repository.
For user setup, see the [API reference](api.md). Report scanner or
installation issues through the repository's GitHub issue tracker.
